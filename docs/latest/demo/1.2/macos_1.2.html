Selection of records can be done either using mouse, keyboard or touch screen. Multiple ranges can be selected for copying records.

Following are keyboard and mouse shortcuts to select records:
ShortcutFunction
Shift + click or arrow keysAdd records to selection
Alt + click or arrow keysRemove records from selection
Cmd + clickToggle selection
Ctrl/Cmd + ASelect All
Ctrl/Cmd + DDeselect All
Ctrl/Cmd + CCopy selected records
Double tap on a cellStart selection
Tap on end cellEnd selection

Context menu items (right click) are also available for these functions.
