# Qvencher

Data Lake Qvencher is a native, offline, high-performance data querying tool available for desktop and mobile platforms.

It offers:
- Local-first privacy model: No data leaves the user's device.
- Broad file format support: Parquet, Avro, Iceberg, SQLite, DuckDB, CSV, JSON, logs, and SQL/ODBC databases.
- Cross-platform: Works on Windows, macOS, Android, and iOS.
- Performance-focused: Capable of handling billions of records efficiently.
- Mobile-first design: Usable on tablets and mobiles.
- Simple, practical UI: Focused on usability without bloat.
